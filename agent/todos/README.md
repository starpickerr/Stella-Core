# 事务

事务是与日程、简报并列的应用。桌面端 `/todos` 提供待办、计划、已完成、全部视图，可创建、编辑、搜索、完成和删除事务。事务可以没有截止日期；设定日期后还可设置时间、优先级及每天、每周、每月、每年重复。重复事务按发生日期单独完成，编辑或删除作用于整个系列。有截止时间的未完成事务会由桌面端轮询并显示系统通知，最多补发过去 24 小时内到期的提醒。

数据在用户级 `todos/todos.db`，与 `calendar/calendar.db` 分开。首次打开会一次性迁移旧版日历实现中的 `calendar_affairs` 及逐次完成、通知记录；更早的 `agenda_handoffs` 任务交接记录也会迁入。迁移完成后不会重复导入已删除的事务。旧日程数据保持在日历数据库中。

简报中的行动条目会同步到事务服务，明确的 `due_at` 成为事务截止时间。来源标识用于去重；用户编辑或完成的事务不会被简报重写。日程服务只处理明确的日程时间。Agent 使用独立的 `todos` 工具，HTTP 接口使用 `/api/todos` 路径。
