# 信息架构与配置入口

2026-10-22。用户确认职责并授权实施；本文记录当前 Desktop 实现，不是候选方案。代码入口为 `App.tsx`、`ConfigurationPages.tsx`、`NavRail.tsx` 与 `DataManagementPage.tsx`，验收入口见文末。

Stella 将信息、执行能力、模型选择与安全授权分开管理。比如用户启用 eLearning MCP 后，在数据中连接账号、选择课程和保存目录，在安全的外部连接中管理来源访问限制，文件写入继续遵守安全策略，在数据使用中选择简报消费哪些信息源，简报设置负责整理规则。启用服务不等于获得访问权限，浏览资源不等于同步正文或放入当前模型上下文。

## 当前导航与权威表单

侧边栏信息区包括数据、知识、记忆；系统区包括模型、Agent 配置、能力、安全、通用、日志；左上角不再保留独立 Agent 按钮。日志使用系统区的文字入口，底部仅保留版本与侧栏控制。其他业务入口保持各自职责。

| 入口 | 当前路由及职责 | 配置归属 |
| --- | --- | --- |
| 数据 | `/data` 默认总览；依次为总览、信息源、数据使用、数据存储 | 已注册服务与可用性、点击卡片进入配置、功能与来源的消费关系、实际存储位置 |
| 知识、记忆 | 原插件贡献页面 | 由业务插件维护编辑器、索引和原存储，数据仅展示引用 |
| 能力 | `/skills` 的插件、工具、技能、MCP 分页 | 安装、生命周期、运行配置；插件设置使用 `view=settings&plugin=<id>` |
| Agent 配置 | 系统区进入 `/agent-settings` | 上下文、执行参数、默认行为 |
| 模型 | `/models` | 厂商地址、协议、模型目录及用途绑定 |
| 安全 | `/security` | 四种既有预设、资源与消费者授权、凭据、审批和审计 |
| 通用 | `/general`，`section=about` 滚动到关于 | 语言、外观、通知、启动、版本和更新 |

同一配置只保留一个权威编辑位置。模型内置厂商、自定义厂商、搜索服务和精简版模型页面显示凭据状态，跳转 `/security?tab=secrets&secret=<name>` 选择具体凭据。首次设置只保存模型路由，缺少凭据时继续到安全中心，不再次显示密钥输入框。自定义厂商先保存元数据，再使用 `CUSTOM:<id>` 管理密钥。Security 使用原持久化字段，不复制配置或修改厂商绑定。来源账号和认证资料仍由独立 MCP 的账号表单维护。

系统访问密码也集中在安全中心。关于区域没有独立重复表单。Apple 日历和提醒事项配置各归对应业务页 `/calendar/settings/apple`、`/todos/settings/apple`，共享底层组件并保留返回入口。

## 来源与 eLearning

`/data/sources/email` 是邮箱账号的唯一表单；`/data/sources/elearning` 是学校账号、课程选择与文件保存目录的唯一表单。`/data?section=usage` 统一编辑功能对象与来源对象的关系，例如简报使用 eLearning 或邮箱；支持添加、移除、启用和停用。只展示可信宿主已经登记的消费者及支持的来源，不管理任务、Agent 或执行记录。简报和 eLearning 配置链接到这一入口，不重复编辑同一关系。能力页的 MCP 入口管理连接与启停，链接来源表单；安全的外部连接页管理连接开关及原有 MCP 课程、消费者与有效期授权；目录写入继续遵守原安全策略，没有在数据页复制授权开关。

总览参考安全总览，使用全宽信息源摘要与数据使用、数据存储卡片，说明职责并展示真实登记数量与状态。信息源按 Provider 聚合：多个邮箱只显示一个 Email 卡片及邮箱数量；可用、部分可用、暂不可用和已停用根据组内实际状态展示。点击整张卡片进入原有配置页，来源不可用时仍可打开配置。移除独立配置按钮和资源预览组件；旧 `section=resources/records` 链接回到信息源列表，不请求正文。聚合只影响展示，原邮箱来源 ID、账号和每个邮箱的消费选择保持独立。

数据是当前用户的全局目录，页面及 API 不再绑定或枚举 Agent、会话和工作区；旧链接的 Agent/会话参数不参与数据选择。临时工作区提供者已移除，旧引用不再显示或读取。Agent 通过已连接服务正常访问，访问限制在安全的外部连接中管理；简报等功能的消费选择不作为 Agent 授权。服务可用、访问已授权和数据已同步仍分别判断。

底层资源查询、采集、导出和事件订阅 API 兼容保留，界面不以订阅编辑器代替功能消费关系。知识和记忆不复制业务编辑器。课程文件同步仍在 eLearning 配置页，单独经过 Data 来源状态与所有者操作检查，使用原 MCP 下载 manifest、目录与写入授权；不覆盖用户修改过的文件，也不等同于删除上游内容。

数据存储展示实际根目录和分类路径，包括业务库、工作文件、插件私有数据、知识记忆、配置日志及已配置的课程下载目录。仅打开存储页时统计大小，不创建尚不存在的目录。原有临时文件和任务缓存清理保留，其他业务存储仅展示并说明归属。

## 兼容与失败处理

`SettingsPage.tsx` 仅承担旧 `tab/section` 链接跳转，不再承载聚合表单；模型、Agent、插件、安全、Apple、关于与数据的旧入口均跳转到对应页面。`/email`、`/elearning` 兼容跳转到来源表单。配置仍使用原 API 和原存储，不清空账号、凭据、课程、会话、简报历史、游标或下载文件。

请求失败显示可重试错误；权限、来源 revision 或启停变化阻止读取结果释放。同步以已保存目录为前提，来源不可用时按钮禁用并提供数据来源入口；服务端独立复查同一条件，界面状态不构成授权。

## 验收与限制

`tests/ui_information_architecture.py`、`ui_settings_entry.py`、`ui_capabilities.py` 验证导航、唯一入口、兼容跳转和返回行为；`ui_model_selection.py` 验证六类模型用途、厂商元数据、首次设置失败重试及到安全的跳转；`ui_managed_models.py` 使用 `tests/fixtures/managed_product` 扩展构建验证精简版模型选择和凭据入口；`ui_security_modes.py` 验证四种模式、凭据选择/保存、键盘和窄窗口；`ui_data_management.py`、`ui_elearning_settings.py` 验证聚合来源、卡片点击与键盘配置、多邮箱原表单、旧预览入口回退、消费关系、下载入口和失败反馈。

后端对应 `tests/test_security_center.py`、`test_data_api.py`、`test_data_browse_scope.py`、`test_data_global_catalog.py`、`test_data_elearning_resources.py` 与 `test_owned_resource_providers.py`。浏览器使用隔离的 API 数据；独立插件/MCP 的实际 RPC、授权和下载路径由上述集成测试验证，不以浏览器 Mock 代替服务验收。实际学校与邮箱账号不用于测试，OS 通知、启动项和应用更新仍由 Electron 平台适配器提供。

初次架构改造基线（2026-10-22）的隔离全量测试为 **2048 PASS / 22 SKIP / 0 FAIL**，并完成上述八组浏览器检查；该历史结果不代替后续变更验收。22 项跳过分别为真实外部 Agent（1）、Windows 集成（3）、工作区外开发 Skill（1）与缺少 PyInstaller 的打包用例（17）。数据四页改造随后运行受影响的数据、简报、MCP 路由、所有者及调用边界测试，共 **279 PASS / 0 FAIL / 0 SKIP**；Desktop lint、typecheck、renderer/main 构建通过。数据管理、eLearning 配置、信息架构和设置入口四组浏览器检查通过，覆盖桌面、620 与 390 窄窗口。浏览器使用隔离数据，不代表真实学校、邮箱账号或平台更新已验收。
