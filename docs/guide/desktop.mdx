<Tabs>
  <Tab title="macOS">
    1. Open the [download page](https://github.com/starpickerr/Stella/releases) and pick the build for your chip:
       - Apple Silicon (M1/M2/M3/M4): download the `arm64` build
       - Intel: download the `x64` build
    2. Open the downloaded `.dmg` and drag Stella into your Applications folder.
    3. Launch Stella from Launchpad or Applications.
  </Tab>
  <Tab title="Windows">
    1. Open the [download page](https://github.com/starpickerr/Stella/releases) and download the Windows installer (`.exe`).
    2. Run the installer and follow the prompts (you can choose the install directory).
    3. Launch Stella from the desktop or Start menu.
  </Tab>
</Tabs>

## Updates

When a newer GitHub Release is published, the desktop client **prompts** you and opens the download page. It does not install in the background. macOS builds are `.dmg` only; unsigned apps may need a right-click → Open the first time.

To ship a new version, edit only the repo-root `VERSION` file (`X.Y.Z`, no `v`; do not run `npm version`). `npm run dist:mac` copies that number into `package.json`. The git tag is `vX.Y.Z`.

```bash
echo 0.0.2 > VERSION
cd desktop && npm install && cd ..
bash desktop/build/build-backend.sh
cd desktop && npm run dist:mac && cd ..
git add VERSION desktop/package.json desktop/package-lock.json
git commit -m "release: v0.0.2"
git tag v0.0.2
git push && git push --tags
```

Then create a published GitHub Release for that tag (not draft / pre-release) and upload `desktop/release/Stella-0.0.2-arm64.dmg`. Full notes: [desktop/README.md](https://github.com/starpickerr/Stella/blob/main/desktop/README.md).

## Desktop-only backend

The Electron client starts a private API on `127.0.0.1`. The old browser frontend and standalone server are removed. The port is selected automatically if `9876` is unavailable; the desktop window receives the actual port from Electron.

## Local Data Storage

All data of the desktop client is stored on your machine:

- **Config directory**: `~/.stella` in your home folder, holding `config.json` (model keys, channels, etc.) along with logs, cache and other runtime data.
- **Workspace**: `~/stella` by default, holding chat history, knowledge base, memory, skills, scheduled tasks and other files produced by the Agent.

Uninstalling the client does not delete these two directories, so your data is preserved across reinstalls. To fully clean up or migrate to another device, just back up or remove the corresponding folders manually.
