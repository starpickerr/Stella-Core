## Installed app

The desktop client checks GitHub Releases and offers a link when a new version is available. Download and install that release; it does not install updates in the background. Your data in `~/.stella` remains available after replacing the app.

## Source checkout

```bash
git pull
.venv/bin/python -m pip install -r requirements.txt
cd desktop
npm ci
npm run dev
```

`npm run dev` rebuilds the current Electron interface and starts its backend. Source and installed builds use the same data in `~/.stella`; the new launch replaces the running desktop instance.
