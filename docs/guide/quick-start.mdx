---
title: Quick Start
description: Start Stella in the Electron desktop client
---

Download the current desktop release from [GitHub Releases](https://github.com/starpickerr/Stella/releases/latest) and open Stella. The Electron client starts its private backend automatically.

For source development:

```bash
git clone https://github.com/starpickerr/Stella.git
cd Stella
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
npm --prefix desktop ci
cd desktop
npm run dev
```

`npm run dev` builds the current interface and starts the desktop backend. See [Desktop setup](/guide/desktop) for packaging and details.

Source prerequisites and Windows commands: [Build from Source](/guide/manual-install).
