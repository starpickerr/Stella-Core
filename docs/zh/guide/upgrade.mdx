## 已安装的客户端

桌面客户端会检查 GitHub Releases，有新版时提示下载。下载安装新版即可；客户端不会在后台自动安装。替换应用后，`~/.stella` 中的数据仍会保留。

## 从源码运行

```bash
git pull
pip install -r requirements.txt
cd desktop
npm install
npm run dev
```

`npm run dev` 会重新构建当前 Electron 界面并启动后端。源码版与已安装客户端共用 `~/.stella` 数据；新启动的客户端会接管旧实例。
