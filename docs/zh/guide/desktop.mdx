## 下载安装

<Card title="前往下载页" icon="download" href="https://github.com/starpickerr/Stella/releases">
  下载 macOS / Windows 客户端安装包
</Card>

<Tabs>
  <Tab title="macOS">
    1. 打开 [下载页](https://github.com/starpickerr/Stella/releases)，根据芯片选择安装包：
       - Apple Silicon（M1/M2/M3/M4）：下载 `arm64` 版本
       - Intel 芯片：下载 `x64` 版本
    2. 打开下载的 `.dmg`，将 Stella 拖入「应用程序」文件夹。
    3. 从启动台或应用程序中打开 Stella 即可。
  </Tab>
  <Tab title="Windows">
    1. 打开 [下载页](https://github.com/starpickerr/Stella/releases)，下载 Windows 安装包（`.exe`）。
    2. 双击运行安装程序，按提示完成安装（可自定义安装目录）。
    3. 从桌面或开始菜单打开 Stella 即可。
  </Tab>
</Tabs>

## 更新

GitHub 上有新 Release 时，桌面端会**提示**并打开下载页，不会在后台自动安装。macOS 只提供 `.dmg`；未签名应用首次打开可能需要右键 → 打开。

发版只改仓库根目录的 `VERSION`（`X.Y.Z`，不要写 `v`，也不要跑 `npm version`）。`npm run dist:mac` 会把该数字同步进 `package.json`。git tag 为 `vX.Y.Z`。

```bash
echo 0.0.2 > VERSION
cd desktop && npm install && cd ..
bash desktop/build/build-backend.sh
cd desktop && npm run dist:mac && cd ..
git add VERSION desktop/package.json desktop/package-lock.json
git commit -m "release: v0.0.2"
git tag v0.0.2
git push && git push --tags
```

然后在 GitHub 为该 tag 建正式 Release（不要 draft / pre-release），上传 `desktop/release/Stella-0.0.2-arm64.dmg`。完整说明见仓库里的 [desktop/README.md](https://github.com/starpickerr/Stella/blob/main/desktop/README.md)。

## 桌面专用后端

Electron 客户端在 `127.0.0.1` 启动私有 API。独立 Web 前端和服务器部署入口已删除。若 `9876` 被占用，客户端会自动选择其它端口并通知桌面界面。

## 本地数据存储

桌面客户端的所有数据都保存在本机：

- **配置文件**：位于用户目录下的 `~/.stella`，包含 `config.json`（模型密钥、通道等配置）以及日志、缓存等运行数据。
- **系统工作空间**：默认位于 `~/stella`，用于存放对话记录、知识库、记忆、技能、定时任务等 Agent 产生的文件。

卸载客户端不会自动删除这两个目录，重装后数据依然保留。如需彻底清理或迁移到其他设备，手动备份或删除对应目录即可。
