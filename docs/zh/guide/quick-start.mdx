---
title: 快速开始
description: 在 Electron 桌面客户端中运行 Stella
---

从 [GitHub Releases](https://github.com/starpickerr/Stella/releases/latest) 下载桌面版并打开 Stella。Electron 客户端会自动启动专用后端。

从源码运行：

```bash
git clone https://github.com/starpickerr/Stella.git
cd Stella
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
npm --prefix desktop ci
cd desktop
npm run dev
```

`npm run dev` 会构建当前界面并启动桌面后端。详见[桌面版指南](/zh/guide/desktop)。

环境要求和 Windows 命令请参阅[源码构建](/zh/guide/manual-install)。
