[skill广场](https://www.skill-marketplace.com/) 是 Stella 的技能市场，可浏览官方、社区和第三方技能并一键安装。


## 功能

- **浏览技能**：按类别和标签筛选
- **搜索技能**：按名称或描述搜索
- **查看详情**：查看技能文档、文件、安装命令和依赖的环境变量
- **一键安装**：复制安装命令即可在 Stella 中使用

## 安装技能

在对话中或终端中执行：

<CodeGroup>
```text 对话
/skill install <name>
```

```bash 终端
stella skill install <name>
```
</CodeGroup>

也可以在对话中浏览 skill广场：

```text
/skill list --remote
/skill search <关键词>
```

第三方技能仍可通过 **GitHub、ClawHub、LinkAI、URL** 安装，见 [安装技能](/zh/skills/install)。

## 贡献技能

请在 [skill广场](https://www.skill-marketplace.com/) 提交。


技能目录结构：

```
your-skill/
├── SKILL.md        # 必需，放在根目录
├── scripts/        # 可选，运行脚本
└── resources/      # 可选，附加资源
```

<Tip>
  技能以 `SKILL.md` 为核心。也可以从详情页下载 `SKILL.md`，给其他支持自定义指令的 Agent 使用。
</Tip>
