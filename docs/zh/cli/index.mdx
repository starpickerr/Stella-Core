---
title: 命令总览
description: 桌面客户端中的对话命令
---

在 Electron 客户端或已连接的消息渠道中输入 `/`，即可查看命令提示。后端由桌面客户端管理；打开或退出应用即可启动或停止。

| 命令 | 说明 |
| --- | --- |
| `/help` | 显示命令帮助 |
| `/status` | 查看会话状态 |
| `/cancel` | 停止当前 Agent 任务 |
| `/steer <instruction>` | 引导当前任务 |
| `/config` | 查看或修改运行配置 |
| `/skill` | 管理技能 |
| `/memory dream [N]` | 运行记忆蒸馏 |
| `/knowledge` | 查看知识库 |
| `/context` | 查看或清理上下文 |
| `/logs` | 查看近期日志 |
| `/version` | 查看版本 |
