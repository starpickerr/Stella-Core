## 🤝 子 Agent

主 Agent 可在对话过程中把独立的任务交给子 Agent 执行。子 Agent 在自己的上下文中完成任务、只返回结论，中间打开的网页、读取的文件和执行的命令都不会进入主对话。

- **独立上下文**：中间过程不占用主对话上下文，节约 token，也让模型注意力更集中。
- **并行执行**：一次可创建多个子 Agent 同时执行，总耗时取决于最慢的一个，每个任务在 Web 与桌面端各对应一张独立卡片。
- **内置与自定义类型**：内置 `general-purpose` 与 `explore` 两种类型，也可在工作区 `subagents/` 下用 `.md` 文件自定义类型，限定系统提示词与可用工具。
- **默认开启**：无需配置，由主 Agent 自行判断是否创建；可在「配置 → Agent 配置」中开关，并在 `config.json` 中调整嵌套层数、并行数与超时。

相关文档：[子 Agent](https://docs.cowagent.ai/zh/multi-agent/subagent)

## 🧠 思考过程与推理力度

- **展示思考过程**：Claude 模型的思考过程可在 Web 与桌面端展示，便于观察模型的推理链路。
- **推理力度可配**：为原生厂商开放推理力度（reasoning effort）配置，覆盖 Claude、DashScope（通义千问）、Kimi、LinkAI 等，并按模型分别记忆各自的设置。DeepSeek-V4 在网关下仍保留其自身的 effort 取值。Thanks @tshicheng (#3007, #3009)

相关文档：[Claude 模型](https://docs.cowagent.ai/zh/models/claude)

## 🌱 自我进化

自我进化能力默认开启，Agent 可在使用过程中沉淀经验、逐步完善自身配置。

- **默认启用**：无需手动开启即可生效。
- **写入更安全**：对无人值守下的写入增加校验与回滚，按工作空间串行化写入，收窄受保护的写入路径，避免误伤工作空间中的任务文件。Thanks @lisheng-SenLee (#3011, #3016)

## 💾 记忆与检索

- **可插拔向量后端**：记忆的向量存储与检索抽象为独立后端，SQLite 仍作为零依赖的默认实现，FTS 行为保持不变，便于接入外部向量库。Thanks @AaronZ345 (#3021)
- **索引修复**：修复分片更新时 trigram FTS5 索引损坏的问题，共享库损坏时可自我修复。

相关文档：[记忆管理](https://docs.cowagent.ai/zh/memory)

## 🎨 自定义绘图厂商

图片生成支持接入自定义的 OpenAI 兼容厂商，配置后可在能力选择与独立生成流程中使用，支持凭据的实时刷新与删除清理。Thanks @AaronZ345 (#3022)

## 🖥 桌面客户端

- **推送通知**：客户端可接收定时任务与主动推送的消息，并弹出系统通知。
- **更新面板**：更新弹窗中新增发布说明链接，直接查看本次变更。
- **自定义厂商模型**：为自定义厂商提供自由填写的模型输入框，管理密钥输入框始终可见。
- **启动更稳健**：修复后端启动被阻塞的问题，启动失败时以非零退出并透出真实错误；`config.json` 损坏时可在启动阶段自愈。

相关文档：[桌面客户端](https://docs.cowagent.ai/zh/guide/desktop)

## 🛠 体验优化与修复

- **SSE 可靠重连**：Web 端补全 SSE 生命周期，网络中断后可携带事件回放重连，减少长任务下的消息丢失。Thanks @lisheng-SenLee (#3014)
- **推理链路展示**：修复推理模式下工具卡片、文件链接与图片展示相关的若干问题。
- **限流退避**：LLM 触发限流时对退避时长设置上限，避免长时间等待。Thanks @tim-korso (#3018)
- **定时任务静默**：无内容可汇报时，定时任务不再发送空消息。
- **服务停止时间**：修复无法接受当日结束时刻（如 23:59）作为服务停止时间的问题。Thanks @Iams4kura (#3020)
- **域名协议解析**：修复 `CLOUD_WEBSITES_DOMAIN` 中显式指定的 http/https 协议未被遵循的问题。Thanks @6vision (#3015)
- **飞书通道**：修复投递延迟的新消息被丢弃的问题。
- **Telegram**：修复 Markdown 渲染，避免长总结把随附文件挤掉。
- **文件回复**：修复带文件回复时文本与其余附件被一并丢弃、以及工具文件链接影响客户端工具卡片的问题。
- **Docker**：安装 tzdata，使 `TZ` 环境变量正确生效。
- **安全加固**：技能文件路径校验中把反斜杠也视为分隔符；云端技能安装逐个校验文件路径。Thanks @LHMQ878 (#3006)

## 📦 升级方式

- **桌面客户端**：可在客户端内自动检查并一键更新，或前往 [下载页](https://cowagent.ai/zh/download/) 获取最新版本。
