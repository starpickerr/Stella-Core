## 🗂 工作空间与文件预览

Agent 生成网页或文稿后，以前只能拿到一个本地路径，得自己复制到浏览器或去目录里翻。本次在 Web 端加入工作空间面板，这类产出可以直接看：

- **文件预览**：生成的 HTML 页面、文档、图片等可在右侧面板直接打开预览，回复中的文件路径也会渲染成可点击的卡片。
- **工作空间浏览**：面板内可浏览和管理工作空间目录下的文件，相当于一个简单的文件管理器。
- **文件引用**：支持将工作空间中的文件拖入对话，或在输入框用 `@` 引用文件与目录，直接加入上下文。(#2990)

## 🔍 编码与文件工具

围绕「在工作空间里读写文件、改代码」这条链路，对基础工具做了一轮系统性优化：

- **新增文件搜索工具**：`search_files` 支持按内容或文件名搜索工作空间，内置 ripgrep 作为默认后端，大目录下速度明显更快。Thanks @Maaayhan (#2982)
- **读取带行号**：`read` 的输出统一带上行号，定位和后续编辑更准确，也便于在对话中引用具体某几行。
- **编辑更稳**：修复模糊匹配时可能改动原有缩进、以及内容重复时定位到错误位置的问题；新增一次替换全部匹配的能力，并在文件被外部改动后给出提醒。
- **写入前语法检查**：写 JSON / YAML / TOML 等结构化文件时会先校验，格式不对直接拦下不落盘；源码文件则以提示形式告知，避免写出坏文件后再花一轮回头修。
- **命令支持后台运行**：启动服务、跟踪日志这类长期运行的命令可以放到后台，随时查看输出或结束进程，不必占着会话干等；前台命令的默认超时也从 30 秒放宽到 120 秒。
- **中止立即生效**：点击中止或使用 `/cancel` 时，正在执行的命令会被真正终止，不用等它自己跑完。

相关文档：[文件搜索](https://docs.cowagent.ai/zh/tools/search-files)

## 🧠 上下文管理

- **主动压缩上下文**：新增 `/compact` 命令，将较早的对话交给模型总结后保留要点，最近几轮保持完整，适合在开始长任务前先腾出空间。
- **命令统一**：`/clear` 统一为清空当前会话上下文，`/context clear` 作为别名继续兼容。
- **默认容量提高**：调高了默认的上下文上限，长对话被裁剪的时机更晚。

相关文档：[上下文管理](https://docs.cowagent.ai/zh/memory/context)

## ✨ 提示词优化

Web 端输入框新增提示词优化功能，可将随手写下的一句话补全为更完整清晰的指令，优化规则支持自定义模板。Thanks @sufan721 (#2989)

## 🖥 桌面客户端

- **飞书通道恢复**：修复 2.1.4 客户端中飞书通道缺失的问题。飞书 SDK 改为首次启用通道时按需下载精简包（约 1MB），不再增大安装包体积。Thanks @EvanProgramming (#2988)
- **主题与外观定制**：客户端改为数据驱动的主题机制，用户消息气泡配色、助手头像等均可定制。
- **更新提示**：同一版本的更新弹窗只自动弹出一次，不再重复打扰。
- **内置文件搜索后端**：Windows 客户端随包内置 ripgrep，文件搜索开箱即用。

下载地址：[CowAgent客户端](https://cowagent.ai/zh/download/)

相关文档：[桌面客户端](https://docs.cowagent.ai/zh/guide/desktop)

## 🔒 安全加固

- **MCP 与文件写入加固**：修复一条可被提示词注入利用的攻击链——恶意内容诱导 Agent 改写 MCP 配置，进而执行任意命令、窃取密钥。Thanks @Correctover (#2968)
- **凭据文件保护**：修复 `edit` 工具可绕过凭据保护、读写 `~/.cow/.env` 的问题。

## 🛠 体验优化与修复

- **bash 配置生效**：修复 `config.json` 中 `tools.bash.timeout` 与 `tools.bash.safety_mode` 被忽略的问题。Thanks @EvanProgramming (#2986)
- **记忆工作空间路径**：修复全局记忆配置中工作空间路径解析不正确的问题。Thanks @Maaayhan (#2992)
- **浏览器启动**：修复重启后浏览器可能提示「个人资料出了点问题」并无法使用的问题。
- **工具反馈准确性**：修复若干让模型白跑一轮的错误反馈，包括把 `grep` / `find` 的正常退出码当作失败、浏览器脚本执行误报语法错误、图片相对路径解析失败等。
- **HTTP 中继超时**：为 HTTP 中继请求增加超时，避免请求长时间挂起。

## 📦 升级方式

- **源码部署**：执行 `cow update` 一键升级，或手动拉取代码后重启。详见 [更新升级文档](https://docs.cowagent.ai/zh/guide/upgrade)。
- **桌面客户端**：可在客户端内自动检查并一键更新，或前往 [下载页](https://cowagent.ai/zh/download/) 获取最新版本。
