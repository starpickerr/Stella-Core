这是 Stella 品牌的第一个测试版本，版本号从 `0.0.1` 起跳，不再沿用上游 2.1.x。

## 桌面端

- macOS 只打 `.dmg`（`Stella-<version>-arm64.dmg` / `x64`）。
- 发现新的 GitHub Release 时**提示**并打开下载页，不会在后台自动安装。
- 未签名安装包首次打开需要右键 → 打开。

## 版本与发版

产品版本只改仓库根目录的 `VERSION` 文件（CLI、Python 包、桌面 `package.json` 在构建时同步）。Git tag 带 `v` 前缀（`v0.0.1`）。

```bash
echo 0.0.1 > VERSION
bash desktop/build/build-backend.sh
cd desktop && npm run dist:mac
git tag v0.0.1 && git push --tags
```

然后在 GitHub 为该 tag 新建 Release 并上传 dmg。完整命令见 [desktop/README.md](https://github.com/starpickerr/Stella/blob/main/desktop/README.md)。
