---
title: コマンド一覧
description: デスクトップクライアントのチャットコマンド
---

Electron クライアントまたは接続済みメッセージチャネルで `/` を入力すると、コマンド候補が表示されます。バックエンドはデスクトップアプリが起動・停止します。

| コマンド | 説明 |
| --- | --- |
| `/help` | ヘルプを表示 |
| `/status` | セッション状態を表示 |
| `/cancel` | 実行中の Agent タスクを停止 |
| `/steer <instruction>` | 実行中のタスクを誘導 |
| `/config` | 実行時の設定を確認・変更 |
| `/skill` | Skill を管理 |
| `/memory dream [N]` | 記憶の蒸留を実行 |
| `/knowledge` | ナレッジベースを確認 |
| `/context` | コンテキストを確認・削除 |
| `/logs` | 最近のログを表示 |
| `/version` | バージョンを表示 |
