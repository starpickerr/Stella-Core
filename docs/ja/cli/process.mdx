---
title: プロセス管理
description: stella コマンドで Stella プロセスのライフサイクルを管理
---

プロセス管理コマンドは Stella バックグラウンドプロセスのライフサイクルを制御します。これらのコマンドはターミナルでのみ使用可能です。

## start

Stella サービスを起動します。デフォルトではバックグラウンドデーモンとして実行され、自動的にログを表示します。

```bash
stella start
```

**オプション：**

| オプション | 説明 |
| --- | --- |
| `-f`, `--foreground` | フォアグラウンドで実行（デーモンとして起動しない） |
| `--no-logs` | 起動後にログを自動表示しない |

## stop

実行中の Stella サービスを停止します。

```bash
stella stop
```

## restart

Stella サービスを再起動します（停止してから起動）。

```bash
stella restart
```

**オプション：**

| オプション | 説明 |
| --- | --- |
| `--no-logs` | 再起動後にログを自動表示しない |

## update

コードを更新してサービスを再起動します。自動的に以下を実行します：

1. 最新コードをプル（`git pull`）
2. 現在のサービスを停止
3. Python 依存パッケージを更新
4. CLI を再インストール
5. サービスを起動

```bash
stella update
```

<Warning>
  `git pull` が失敗した場合（ローカルの未コミットの変更がある場合など）、更新は中止され、サービスには影響しません。
</Warning>

## status

Stella サービスの実行状態を確認します。プロセス情報、バージョン、現在のモデルとチャネルの設定を含みます。

```bash
stella status
```

## logs

サービスログを表示します。

```bash
stella logs
```

**オプション：**

| オプション | 説明 | デフォルト値 |
| --- | --- | --- |
| `-f`, `--follow` | ログ出力を継続的に追跡 | いいえ |
| `-n`, `--lines` | 最近の N 行を表示 | 50 |

例：

```bash
# 最近の100行を表示
stella logs -n 100

# ログを継続的に追跡
stella logs -f
```

## install-browser

[ブラウザツール](/ja/tools/browser)のために Playwright と Chromium ブラウザをインストールします。

```bash
stella install-browser
```

<Tip>
  ブラウザツール（Web ブラウジング、スクリーンショットなど）を使用する場合にのみ必要です。
</Tip>

## run.sh との互換性

Stella CLI がインストールされていない場合は、`run.sh` でサービスを管理できます：

| stella コマンド | run.sh 相当 |
| --- | --- |
| `stella start` | `./run.sh start` |
| `stella stop` | `./run.sh stop` |
| `stella restart` | `./run.sh restart` |
| `stella update` | `./run.sh update` |
| `stella status` | `./run.sh status` |
| `stella logs` | `./run.sh logs` |

<Note>
  `stella` コマンドの使用を推奨します。よりシンプルな構文と豊富な機能を提供します。ワンクリックインストールスクリプトで自動的にインストールされます。
</Note>
