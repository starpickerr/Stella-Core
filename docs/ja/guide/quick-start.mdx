---
title: クイックスタート
description: Electron デスクトップ版で Stella を起動
---

[GitHub Releases](https://github.com/starpickerr/Stella/releases/latest) からデスクトップ版をダウンロードして Stella を起動します。Electron が専用バックエンドを自動的に起動します。

ソースから実行する場合：

```bash
git clone https://github.com/starpickerr/Stella.git
cd Stella
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
npm --prefix desktop ci
cd desktop
npm run dev
```

`npm run dev` は最新の画面をビルドしてデスクトップ用バックエンドを起動します。詳細は[デスクトップガイド](/ja/guide/desktop)を参照してください。

必要な環境と Windows のコマンドは[ソースからビルド](/ja/guide/manual-install)を参照してください。
