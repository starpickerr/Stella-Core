Stella は、Agent の実行環境を内蔵したすぐに使えるデスクトップクライアントを提供しています。**Python や依存関係を手動でインストールする必要はありません**。ダウンロードしてインストールするだけで、ローカルでスーパー AI アシスタントを実行できます。

## ダウンロードとインストール

<Card title="ダウンロードページへ" icon="download" href="https://github.com/starpickerr/Stella/releases">
  macOS / Windows 用インストーラーをダウンロード
</Card>

<Tabs>
  <Tab title="macOS">
    1. [ダウンロードページ](https://github.com/starpickerr/Stella/releases) を開き、チップに合わせて選択します：
       - Apple Silicon（M1/M2/M3/M4）：`arm64` 版をダウンロード
       - Intel：`x64` 版をダウンロード
    2. ダウンロードした `.dmg` を開き、Stella を「アプリケーション」フォルダにドラッグします。
    3. Launchpad またはアプリケーションから Stella を起動します。
  </Tab>
  <Tab title="Windows">
    1. [ダウンロードページ](https://github.com/starpickerr/Stella/releases) を開き、Windows インストーラー（`.exe`）をダウンロードします。
    2. インストーラーを実行し、画面の指示に従います（インストール先を選択できます）。
    3. デスクトップまたはスタートメニューから Stella を起動します。
  </Tab>
</Tabs>

## アップデート

新しい GitHub Release があると、デスクトップは**案内**してダウンロードページを開きます。バックグラウンドインストールはしません。macOS は `.dmg` のみです。未署名アプリは初回、右クリック → 開くが必要な場合があります。

公開時はリポジトリ直下の `VERSION` だけを `X.Y.Z` にします（`v` なし。`npm version` は使わない）。`npm run dist:mac` がその番号を `package.json` にコピーします。git タグは `vX.Y.Z` です。

```bash
echo 0.0.2 > VERSION
cd desktop && npm install && cd ..
bash desktop/build/build-backend.sh
cd desktop && npm run dist:mac && cd ..
git add VERSION desktop/package.json desktop/package-lock.json
git commit -m "release: v0.0.2"
git tag v0.0.2
git push && git push --tags
```

そのタグで正式な GitHub Release を作り（draft / pre-release ではない）、`desktop/release/Stella-0.0.2-arm64.dmg` をアップロードします。詳細は [desktop/README.md](https://github.com/starpickerr/Stella/blob/main/desktop/README.md)。

## デスクトップとコマンドラインの違い

- **デスクトップクライアント**：自分の PC での個人利用に最適。すぐに使え、GUI 操作。新しい GitHub Release があれば手動ダウンロードを案内します。
- **コマンドラインデプロイ**：開発者やサーバーでの長期運用に最適で、カスタマイズ性が高い。詳しくは [クイックスタート](/ja/guide/quick-start) を参照。

## ブラウザからのアクセス

デスクトップクライアントは起動するとローカルでポート `9876` をリッスンし、そのバックエンドは Web コンソールとまったく同じです。そのため、アプリを開いている間はブラウザで `http://localhost:9876` にアクセスすれば、クライアント UI と同じ完全な体験が得られます。

このポートが使用できない場合（Windows で Hyper-V/WSL2 に予約されている場合など）、クライアントは自動的に別のポートへフォールバックして正常に起動します。実際のポートは `run.log` の `Local access` 行で確認でき、`config.json` の `web_port` で固定することもできます。

## ローカルデータの保存

デスクトップクライアントのすべてのデータはお使いのマシンに保存されます：

- **設定ディレクトリ**：ホームフォルダの `~/.stella`。`config.json`（モデルキーやチャネルなどの設定）のほか、ログ・キャッシュなどの実行データが含まれます。
- **ワークスペース**：デフォルトは `~/stella`。会話履歴・ナレッジベース・記憶・スキル・定期タスクなど、Agent が生成したファイルが保存されます。

クライアントをアンインストールしてもこの 2 つのディレクトリは自動削除されないため、再インストール後もデータは保持されます。完全に削除したい場合や別のデバイスへ移行する場合は、該当するフォルダを手動でバックアップまたは削除してください。
