## インストール済みアプリ

デスクトップクライアントは GitHub Releases を確認し、新版がある場合はダウンロードを案内します。新版をインストールしても `~/.stella` のデータは保持されます。バックグラウンドでの自動インストールは行いません。

## ソースから実行

```bash
git pull
.venv/bin/python -m pip install -r requirements.txt
cd desktop
npm ci
npm run dev
```

`npm run dev` は現在の Electron 画面を再ビルドし、バックエンドを起動します。ソース版とインストール版は `~/.stella` のデータを共有し、新しく起動したクライアントが実行中のインスタンスを引き継ぎます。
