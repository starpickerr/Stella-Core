[skill広場](https://www.skill-marketplace.com/) は Stella 向けの Skill マーケットプレイスです。公式・コミュニティ・サードパーティの Skill を閲覧し、ワンクリックでインストールできます。

<img src="/images/placeholder-image.svg" width="800" />

## 機能

- **閲覧** — カテゴリとタグでフィルタ
- **検索** — 名前または説明で検索
- **詳細** — マニフェスト、ファイル、インストールコマンド、必要な環境変数
- **ワンクリックインストール** — コマンドをコピーして Stella で実行

## インストール

チャットまたはターミナル:

<CodeGroup>
```text チャット
/skill install <name>
```

```bash ターミナル
stella skill install <name>
```
</CodeGroup>

チャットから skill広場を閲覧:

```text
/skill list --remote
/skill search <キーワード>
```

**GitHub、ClawHub、LinkAI、任意の URL** からもインストールできます。詳しくは [スキルのインストール](/ja/skills/install)。
