[skill广场](https://www.skill-marketplace.com/) is the skill marketplace for Stella: browse official, community, and third-party skills and install them in one click.

<img src="/images/placeholder-image.svg" width="800" />

## Features

- **Browse skills** — filter by category and tags
- **Search skills** — find skills by name or description
- **View details** — read the skill manifest, files, install command, and required environment variables
- **One-click install** — copy the install command and run it in Stella

## Installing a skill

Run the install command in chat or in your terminal:

<CodeGroup>
```text Chat
/skill install <name>
```

```bash Terminal
stella skill install <name>
```
</CodeGroup>

You can also browse the marketplace from chat:

```text
/skill list --remote
/skill search <keyword>
```

Third-party skills can still be installed from **GitHub, ClawHub, LinkAI, or any URL**. See [Installing skills](/skills/install).

## Contributing a skill

Submit skills on [skill广场](https://www.skill-marketplace.com/).


<img src="/images/placeholder-image.svg" width="800" />

Skill file layout:

```
your-skill/
├── SKILL.md        # required, in the root
├── scripts/        # optional, runtime scripts
└── resources/      # optional, additional assets
```

<Tip>
  Skills are built around the `SKILL.md` manifest. You can also download `SKILL.md` from a skill's detail page and use it with any Agent that supports custom instructions (OpenClaw, Cursor, Claude Code, and more).
</Tip>
