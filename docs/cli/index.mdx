---
title: Commands Overview
description: Chat commands in the desktop client
---

In the Electron client or a connected messaging channel, type `/` to see command suggestions. The desktop client owns the backend process; launch or quit the app to start or stop it.

| Command | Description |
| --- | --- |
| `/help` | Show command help |
| `/status` | Show session status |
| `/cancel` | Stop the active Agent task |
| `/steer <instruction>` | Guide the active task |
| `/config` | View or update runtime settings |
| `/skill` | Manage skills |
| `/memory dream [N]` | Run memory distillation |
| `/knowledge` | View knowledge base |
| `/context` | View or clear context |
| `/logs` | Show recent logs |
| `/version` | Show version |
