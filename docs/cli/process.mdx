title: Process Management
description: Manage Stella process lifecycle with stella commands
---

Process management commands control the Stella background process. These commands are only available in the terminal.

## start

Start the Stella service. Runs as a background daemon by default and automatically tails logs.

```bash
stella start
```

**Options:**

| Option | Description |
| --- | --- |
| `-f`, `--foreground` | Run in foreground, not as a background daemon |
| `--no-logs` | Don't tail logs after starting |

## stop

Stop the running Stella service.

```bash
stella stop
```

## restart

Restart the Stella service (stop then start).

```bash
stella restart
```

**Options:**

| Option | Description |
| --- | --- |
| `--no-logs` | Don't tail logs after restart |

## update

Update code and restart the service. Automatically performs:

1. Pull latest code (`git pull`)
2. Stop current service
3. Update Python dependencies
4. Reinstall CLI
5. Start service

```bash
stella update
```

<Warning>
  If `git pull` fails (e.g., uncommitted local changes), the update aborts and the service remains unaffected.
</Warning>

## status

Check Stella service status, including process info, version, and current model/channel configuration.

```bash
stella status
```

## logs

View service logs.

```bash
stella logs
```

**Options:**

| Option | Description | Default |
| --- | --- | --- |
| `-f`, `--follow` | Continuously tail log output | No |
| `-n`, `--lines` | Show last N lines | 50 |

Examples:

```bash
# View last 100 lines
stella logs -n 100

# Continuously tail logs
stella logs -f
```

## install-browser

Install Playwright and Chromium browser for the [browser tool](/tools/browser).

```bash
stella install-browser
```

<Tip>
  Only needed when using browser tools (web browsing, screenshots, etc.).
</Tip>

## run.sh Compatibility

If Stella CLI is not installed, you can use `run.sh` to manage the service:

| stella command | run.sh equivalent |
| --- | --- |
| `stella start` | `./run.sh start` |
| `stella stop` | `./run.sh stop` |
| `stella restart` | `./run.sh restart` |
| `stella update` | `./run.sh update` |
| `stella status` | `./run.sh status` |
| `stella logs` | `./run.sh logs` |

<Note>
  The `stella` command is recommended — it provides cleaner syntax and richer features. It is automatically installed via the one-click install script.
</Note>
