# 桌面端界面统一实施参考：页面顶部横线与全宽主体

本文配合 [需求与验收](requirements.md#7-桌面端页面顶部与宽度统一) 使用。用户已确定主要内容采用“全部铺满可用宽度”。本文件基于 2026-10-10 的桌面端代码核查，供开发 Agent 定位和验收；界面尚未修改。

## 统一后的页面结构

以 `desktop/src/renderer/src/App.tsx` 中侧边栏右侧的主内容区域为边界，不把侧边栏或可选会话列表算进页面宽度。全局窗口标题栏已有一条贯穿主内容区的底线；每个内置页面在其下方使用统一的页面头部。头部从主内容区左缘延伸到右缘，容纳标题、简短说明和主要操作，底部恰有一条连续分隔线。聊天页也按同一头部位置处理，不能只依赖全局标题栏；标题栏与页面头部相邻时不叠加重复边框。

可复用的结构如下，类名仅示意，实际应沿用项目现有颜色与间距 token：

```tsx
<div className="flex-1 min-w-0 min-h-0 flex flex-col">
  <header className="shrink-0 border-b border-default px-4 sm:px-6 pt-5 pb-3">
    {/* 页面标题、说明、主要操作 */}
  </header>
  <main className="flex-1 min-w-0 min-h-0 overflow-y-auto px-4 sm:px-6 py-5">
    {/* 主内容占满 main 的可用宽度；分栏也在 main 内铺满 */}
  </main>
</div>
```

页面级分隔线放在全宽头部容器上，不放在 `max-w-*` 内容列、标签栏或卡片中；同一边界只画一条。页面正文保留统一左右内边距，宽窗口不额外留居中大空白。长列表、表格、卡片组、图表、日历、聊天记录和详情可以按数据采用网格或分栏，但它们的**整体布局容器**不能再使用 `max-w-* mx-auto` 限定为中间窄列。单个输入框、按钮、简短说明、弹窗和局部卡片可限制自身宽度，不能借此限制整页主体。窄窗口改为换行、可折叠分栏或竖排，避免横向滚动和遮挡。

## 开发验收要点

1. 建议抽出或复用页面外壳／头部组件，统一标题、说明、操作和底线，避免每个页面独立写出不同高度和线宽；现有业务组件保持原职责。不要仅把居中 `max-w-*` 的数值调大，主内容容器应真正占满可用宽度。
2. 对上述 14 个路由逐个检查列表、详情、空状态、加载状态和标签切换；顶部页面级线的左右端应与主内容区两边界对齐。页面内标签线或卡片线可以是局部线，但不会与页面头部线重叠。
3. 在宽窗口、窄窗口及侧边栏展开／收起状态下实际运行桌面界面；检查主要内容的可用宽度、无水平溢出、交互控件不被遮挡，详情返回和滚动不退化。跨页面比较顶部标题基线、左右内边距、分隔线位置与颜色。
4. 改变可观察布局前按仓库规则增加适当的失败测试，完成后运行增量检查和浏览器交互验证；对视觉宽度与线条连贯性保留截图证据。
